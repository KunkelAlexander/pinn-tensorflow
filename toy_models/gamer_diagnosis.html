GAMER: separate the patch operator, gravity, and level coupling

Pinned public commit e36797538a1a5eaa456bc51ad44faf2b201a4aef. Python reconstructions and controlled problems; no compiled GAMER run and no reproduction of a cosmological halo.

Result: the actual-table Gram-FE kinetic update is accurate for well-resolved smooth waves, while second-order gravity dominates a moving-core error budget. A six-level Poisson toy develops inherited tidal error that a 1D Poisson test cannot represent. A separate 1D boundary-time test produces percent-level error in both variants that survives doubling the fine resolution, but only for complex temporal interpolation. Weakly growing short-wave patch modes and a MATMUL table-precision floor remain additional findings, not established causes of the user's halo discrepancy.

What was reconstructed, and what was not

The kinetic column update uses GAMER's actual patch-size-8 tables: 16 physical cells, 8 ghost cells on each side, 14 boundary samples and 32 extension cells. The default source sets DT__FLUID=0.2, which produces dt/(eta dx²)=4(0.2)/pi=0.254648. The implemented Taylor polynomial has powers 0 through 6. MATMUL uses exp[-16 log(10)(k/kmax)^100]; FFT uses exp[-32 log(10)(k/kmax)^200]. These are reconstructed as written, rather than assumed identical. See mesh constants, default timestep, MATMUL builder and FFT update.

MATMUL table contractions use 55 decimal digits before the resulting update is cast to float64. This prevents a naive double-precision port from introducing artificial cancellation error; it does not reproduce binary128 rounding exactly. FFT is tested both through a high-precision fused linear map and through its actual factorized projection, extension, FFT and inverse-FFT sequence. The coupled FFT runtime check disagrees with its fused control by at most 1.57e-09 in wave norm.

Input/output fields are double precision unless explicitly labeled otherwise. Production single precision, GPU execution, 3D sweep ordering, density floors, mass corrections, moving refinement, and HJM-wave transitions are outside this reconstruction. The user has observed the discrepancy with both FFT and MATMUL; therefore a difference between their filters or arithmetic is not treated as the main explanation.

3. Why a 1D Poisson toy can miss a 3D problem

If two fine-grid Poisson solutions have the same source and differ only in boundary values, their difference satisfies Laplace's equation. In 1D, delta Phi = a + bx. The constant changes global phase and the slope produces uniform acceleration. After removing translation, neither directly changes the internal structure of an isolated core in a linear external field. This statement assumes correct fine sources, boundaries outside the core, and a converged solve; source errors or interfaces through the core can still matter in 1D.

In two or three dimensions, harmonic errors can contain tides. For example delta Phi=epsilon(x²-y²) has zero Laplacian and nonzero Hessian. A small residual therefore does not certify the correct tidal field. This provides a concrete reason to supplement 1D tests with a cheap multidimensional elliptic control.

The new 2D problem contains two positive Gaussian density clumps, periodic mean subtraction, and six nested central patches. Every child uses the exact analytic density and a direct FD2 solve, so there is no wave-restriction error or relaxation stopping error. Boundary values come from the parent using quadratic or quartic tensor-product interpolation. This is a controlled nested Poisson model, not a port of GAMER's cell-centered interpolation or boundary stencil.

A separate exact 3D Gaussian-in-a-trap calculation verifies that a trace-free quadratic potential error can change central density and shape despite zero Poisson residual. Its imposed amplitudes are illustrative, larger than the small hierarchy error measured above, and are not inferred GAMER errors. The response is in the JSON; it is not a soliton or halo calculation.

4. A 1D failure shared by FFT and MATMUL: time interpolation of phase

This control prescribes exact parent wave values at both parent times and exact spatial ghost values. The fine region contains four patch groups. Four fine steps fit inside a parent interval. Only the interpolation between parent times is changed.

For a plane wave rotating at omega, interpolating its real and imaginary parts gives a chord through the complex plane. At the midpoint its amplitude is multiplied by cos(omega DeltaT/2). A constant potential increases omega while leaving the continuum density unchanged. Thus this interpolation introduces a gauge-dependent amplitude error even with perfectly accurate gravity and spatial resolution.

The corresponding amplitude e-folding counts range from approximately 1.3e5 to 1.1e6 steps in these probes. These are extrapolations, not cosmological forecasts: mode seeding and nonlinear evolution are unknown. Smaller timesteps do not monotonically reduce the per-step growth, and taking more steps changes cumulative amplification. Recording actual fine-level step counts and short-wave power is therefore worthwhile before declaring the kinetic operator irrelevant.

6. A narrower MATMUL precision defect, not the shared halo explanation

The stored MATMUL extension coefficients reach 6.86e9. Although declared as float128 constants, the DFT entries differ from high-precision analytic values at roughly double-precision scale (6.84e-17 maximum entry error). With filtering disabled and dt=0, the reconstructed stored-table operator differs from the exact crop by 9.62e-07 in operator norm; analytic DFT tables reduce that control to 2.51e-44.

However, correcting only DFT tables does not improve the observed smooth-wave floor in the actual filtered update. Reconstructing the extension from the FFT branch's factored tables at high precision, retaining the MATMUL filter, does improve it. This negative control prevents attributing the whole issue to DFT rounding alone.

What to investigate next in GAMER

  1. Separate inherited boundary error from relaxation error. On a small multidimensional frozen-density hierarchy, compare potential Hessians from the current solve with a global accurate reference. Inspect the trace-free part after removing constant potential and uniform acceleration. Tightening a local residual alone does not test this.
  2. Check actual temporal-interpolation branches and parent phase advance. If OPT__INT_PHASE=0 applies, the constant-potential plane wave is a cheap regression test. Compare exact or synchronized parent data before changing spatial interpolation methods. If phase interpolation is active, use interfering waves and phase nodes rather than claiming the single-wave result applies.
  3. Log cumulative fine-level updates and short-wave contamination. The weakly growing modes provide a concrete long-run kinetic hypothesis. Their excitation must be measured, not assumed from the eigenvalues.
  4. Use resolution changes that isolate the hierarchy. Refining the whole hierarchy, refining only the finest region, and shortening parent time intervals are different experiments. The user reports that doubling resolution did not resolve the investigation; which of these was changed remains important.

Assessment: gravity remains the strongest demonstrated error source for a well-resolved moving core in this round. The multidimensional boundary channel explains why some 1D tests can miss it. The time-interpolation test supplies a common FFT/MATMUL failure with a clear intervention, but only under its stated configuration. None yet proves the cause of the user's halo-profile discrepancy.
